### Üzerinde çalıştıklarım

**Kurumsal Linux dağıtımı** — Ubuntu tabanlı, markalı, zero-touch kurulan bir
kurumsal masaüstü dağıtımı. Kurulum sonrası elle yapılandırma gerektirmiyor.
